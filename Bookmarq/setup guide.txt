# Bookmarq Project Setup Guide

Welcome to the Bookmarq project! Follow these instructions to get the application running smoothly on your local machine. 

## 🏗 Git Repository Folder Structure
When creating the final ZIP or uploading to GitHub, use this exact structure so the frontend and backend are kept isolated but within the same monorepo:

```text
bookmarq-project/
├── .gitignore                   # Root gitignore (ignore node_modules, target, etc.)
├── README.md                    # This setup guide
│
├── backend/                     # Spring Boot Application
│   ├── pom.xml
│   ├── src/
│   │   ├── main/java/...        # Java Source Code
│   │   └── main/resources/      # application.yml, application-local.yml, db/migrations
│   └── target/                  # (GIT IGNORE THIS DIRECTORY)
│
├── frontend/                    # React + Vite Application
│   ├── package.json
│   ├── vite.config.ts
│   ├── src/                     # React Source Code
│   └── node_modules/            # (GIT IGNORE THIS DIRECTORY)
│
└── components/                  # Shared UI components (Originkit)
    └── originkit/               # 3D Tunnel and UI components imported by Frontend
```
> [!NOTE] 
> The `components/originkit` folder exists outside the `frontend` directory. The Vite config is already set up to correctly resolve it!

## 🚀 Prerequisites

Before you start, ensure you have the following installed:
1. **Java Development Kit (JDK) 17+**
2. **Node.js (v18+)**
3. **Microsoft SQL Server** (Developer or Express edition) installed locally, **OR** Docker if you prefer running SQL Server in a container.

---

## 🛠 Step 1: Database Setup (SQL Server)

The backend is configured to connect to a local SQL Server instance. It uses the `sa` account by default.

### Option A: Using Local SQL Server Installation
1. Open SQL Server Management Studio (SSMS).
2. Connect to `localhost` (or `localhost\SQLEXPRESS`).
3. Create a new empty database named **`bookstore`**.
4. Ensure your server authentication is set to **SQL Server and Windows Authentication mode**.
5. Enable the `sa` user and set the password to `YourStr0ng!Pass`.

### Option B: Using Docker (Easier)
If you have Docker installed, simply run this command in your terminal to spin up a pre-configured SQL Server:
```bash
docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=YourStr0ng!Pass" \
   -p 1433:1433 --name sqlserver \
   -d mcr.microsoft.com/mssql/server:2022-latest
```
*(You still need to connect to it via a database client like DBeaver or SSMS to create the `bookstore` database before running the backend).*

---

## ⚙️ Step 2: Start the Backend (Spring Boot)

The backend uses Flyway to automatically create all the necessary database tables and insert sample data on startup.

1. Open your terminal and navigate to the `backend` folder:
   ```bash
   cd backend
   ```
2. Start the Spring Boot application using Maven:
   ```bash
   ./mvnw spring-boot:run -Dspring-boot.run.profiles=local
   ```
   *(On Windows Command Prompt, use `mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=local`)*
3. Wait for the terminal to output `Started BookstoreApplication`. The backend is now running on **`http://localhost:8080`**.

---

## 🎨 Step 3: Start the Frontend (React + Vite)

The frontend is pre-configured to proxy all API requests (like `/api/...`) to your backend on port 8080. No absolute paths exist, so it will work right out of the box!

1. Open a **new** terminal window and navigate to the `frontend` folder:
   ```bash
   cd frontend
   ```
2. Install the necessary Node dependencies:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to the URL provided in the terminal (usually **`http://localhost:5173`**).

> [!SUCCESS]
> **You're all set!** 
> - The 3D tunnel will load immediately.
> - The book catalogue will fetch quickly thanks to backend caching.
> - Any changes you make to the React code will instantly reflect in the browser.
